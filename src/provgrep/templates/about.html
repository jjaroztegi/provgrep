About provgrep

provgrep searches functions from public repositories on GitHub, each read at a pinned commit, and shows every one with the license it is under, the evidence for that license and its copyright notices. Code with no license that lets it be shared is linked to, not shown. Licenses are as detected, not concluded, and they are not legal advice: the evidence is there to be checked. Privacy

There are no accounts, cookies, analytics or requests to anyone else: the page loads only its own script, styles and fonts. The server keeps no log of what is searched. To share the load fairly it counts each address's searches in memory for a few minutes, and nothing else about it. The site is served through Cloudflare, which sees every request, the search in it included, under its own privacy policy.

Email addresses are removed from what is indexed: from copyright notices, comments and docstrings. Authors are named only as their notices name them.

Removal

To have a repository, a file or a function left out of the index, or to report personal data in a result, open a removal request with its link. What is left out stays out of every later build of the index; a removal takes effect when the index is next built.
